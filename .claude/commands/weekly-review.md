# weekly-review

Run these three and read all of the output:

1. `node scripts/shots.mjs shows --json`
2. `node scripts/shots.mjs attention --json`
3. `node scripts/shots.mjs over-bid --json` and `node scripts/shots.mjs rebate --json`

Write five short sections: where each show stands, the three things to fix this week, shots over bid and whether a change order covers them, the rebate gap, and who is overbooked. Name the owner from the records or say no owner is recorded. Save it with `/draft-weekly-review`.
