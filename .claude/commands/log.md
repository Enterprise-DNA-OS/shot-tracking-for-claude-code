# log

Run `node scripts/shots.mjs log-time <task> --hours=<h> [--person=<name>] [--date=YYYY-MM-DD] [--location=AU|NZ|offshore] [--note="..."]`. Location defaults to where the person works; ask if they worked somewhere else that day, because location decides whether the time counts toward a rebate. Never log time in the future.
