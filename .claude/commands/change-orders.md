# change-orders

List with `node scripts/shots.mjs change-orders --json`. Raise with `node scripts/shots.mjs raise-change <shot> --days=<d> --amount=<dollars> --description="..."`. Record the client's answer with `node scripts/shots.mjs decide-change <ref> --status=sent|approved|declined`. Use `/draft-change-order` to write the note to the client.
