# rebate

Run `node scripts/shots.mjs rebate --json`. Explain qualifying spend, the threshold, the gap, the estimated rebate at the scheme rate, spend outside the country (does not count), vendor spend with no evidence, and in-country hours that cannot be costed because the person has no day rate. Run `npm run docs -- rebate-spend-schedule` for the printable schedule. This is a working estimate for the producer and the accountant, not a claim.
